# Programmable Awareness

> Scope: portable invariant for AI coding agents, Labs, and agentic systems.

## Principle

Awareness is a programmable operating layer.

In this seed, awareness means operational self-exposure: the system can surface
its identity, sources, memory state, uncertainty, boundaries, side effects,
available tools, current residue, and next action before it acts.

That layer lets humans steer systems that are increasingly capable and difficult
to inspect from output alone.

## Why It Transfers

Tools change. Models improve. Context windows grow. Boot procedures and compact
recovery may become lighter.

The invariant remains:

```text
state exposure -> source alignment -> boundary recognition -> action choice
-> verification -> memory update
```

This is a programming surface. A node can be configured to:

- read the closest source before acting;
- name verified territory, memory, inference, and residue;
- expose uncertainty and side effects;
- choose the correct action gate;
- record what should survive to the next instance;
- promote stable corrections into reusable rules.

## Design Rule

Treat awareness as part of the system API.

For every agentic workflow, define:

- what the system must know before action;
- where that knowledge lives;
- how the system exposes it;
- which action gates depend on it;
- how verification updates it;
- which lessons become portable invariants.

## Public Language

For public portfolio or product language, use concrete expressions:

- context continuity;
- state exposure;
- recoverability;
- human steering;
- verification loops;
- memory of failures;
- reusable operating rules.

The short slogan is valid:

```text
The seed of awareness is our investment for the future.
```

## Relation To Other Seed Layers

- Boot router classifies the transition.
- Knowledge-safety projection recovers relevant deposits.
- Operational plans preserve why and how.
- Cascade awareness checks propagation.
- Auto-learn turns corrections into rules.
- Installer option routing decides which awareness capabilities are born with a
  node.

Awareness is the invariant that connects these layers.
