# Related Seed Resources

Status: installer-facing reference.

Seed installs portable THIA/D-ND operating functions, kernels, guardrails,
memory and capability routing. Design seeds are intentionally kept in their own
repository.

When a project needs UX/UI/design consistency, workspace shells, navigation
models, domain templates, inspector surfaces or THIA-aware assistant UI, use:

```text
Design seed repo:
https://github.com/GrazianoGuiducci/d-nd-ux-ai-seed
```

Use the D-ND portfolio as the public orientation layer for examples and
adoption context:

```text
D-ND portfolio / public ecosystem:
https://d-nd.com
```

## Install-Time Meaning

An installing AI coder should not copy design components from `d-nd-seed`.
Instead:

1. Install or read `d-nd-seed` for operating behavior.
2. If the task touches UI/design/navigation/templates, inspect
   `d-nd-ux-ai-seed`.
3. Select the smallest complete design seed.
4. Preserve `data-thia-*` awareness attributes where assistant context matters.
5. Verify desktop and mobile before promoting the result.

This avoids duplicate truth: THIA/D-ND functions live in Seed; reusable design
patterns live in the design seed repo; public examples belong in the portfolio.
